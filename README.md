# Candy Shop Website

The official front-end static website for our retail candy shop located in Skänninge, Sweden.

## Overview
- Built with plain HTML5, CSS3, and JavaScript.
- Features store location, opening hours, product catalog displays, and integrated Google Maps navigation.
- Hosted on GitHub Pages.
